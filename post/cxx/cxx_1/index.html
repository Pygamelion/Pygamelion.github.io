变量类型

正数原码、反码和补码相同，负数的符号位是1，补码为反码取反后二进制+1 补码之后 → 减法和加法一样操作。有符号和无符号int的编码位数相同，但是对编码的解释不一样…相当于把原来的2147483648之后的内容用来表示从-2147483648开始到-1的负数了

int a = -2147483647;
unsigned int b = 2147483649;

当无符号数和有符号数运算时，有符号的负数 → 一个比较大的无符号正数，所以有一个坑，Vscode的C/C++插件会补全这样的for循环，如果用来比较或计算要留心…

// size_t 在64位系统上相当于 unsigned long 或 unsigned long long
for (size_t i = 0; i < size; i++)
{
  std::cout << std::boolalpha << (i < -1) << '\n'; // 结果为 true
}

  flowchart TD
    A(value) -->B(glvalue)
    A --> C(rvalue)
    B -->D[lvalue]

    C -->E[xvalue]

  • 左值是有名称，能取地址的值—高级语言中的名称就是汇编语言中的地址
  • 右值可能是栈上的匿名变量/机器指令的一部分或者直接存在寄存器里

无论是左值引用还是右值引用都必须在声明时初始化，左值引用只能被左值初始化；右值引用只能被右值初始化，它们都是地址，引用相当于指针常量，只能在声明时初始化并且不能更改

只有同时满足下列条件，右值引用效率更高：

  1. 右值是一个对象，对象含有指向堆空间数据的指针成员
  2. 右值作为函数参数传递
  3. 函数内部对右值对象数据进行了拷贝操作
class Object
{
public:
    Object(){m_data = new Data()}
    Object(const Object& obj) {m_data = new Data(obj.m_data);};
    Object(Object&& obj) = default;
    ~Object(){delete m_data;m_data=nullptr;}
private:
    Data *m_data; //满足条件1
};

std::vector<Object> vec;
vec.push_back(Object()); //满足条件2和3

完美转发

所谓“完美”：即不仅能准确地转发参数的值，还能保证被转发参数的左值、右值属性不变，std::forward专门代替std::move进行转发

template<typename T, typename... Args>
unique_ptr<T> make_unique(Args&&... args)
{
    return unique_ptr<T>{new T{std::forward<Args>(args)...}}
}

智能指针

单独所有权和共享所有权

std::unique_ptr<int> uptr{new int(10)};
int* p = uptr.get();
uptr = nullptr; // unique_ptr 指向改变值就销毁了
std::cout << *p << '\n'; // 未定义行为 UB

std::shared_ptr<int> sptr{new int(11)};
int* p1 = uptr.get();
// std::shared_ptr<int> sptr1 = sptr; 
sptr = nullptr; // 这个也会销毁，由于指向内存的共享指针数量为0
std::cout << *p1 << '\n'; // 未定义行为 UB

现代Cxx好像不建议再到处手写new和delete这样的东西了， 可以使用std::make_unique和std::make_shared更高效创建(尤其是有数据和控制块的shared_ptr)，并且会避免构造函数抛出异常时内存泄漏，但是如果想要给这些智能指针使用自定义删除器，就不能使用make_函数，而需要自己构造智能指针并为资源分配内存

注意避免循环引用造成引用计数无法归0 → 双向引用时至少一方要使用weak_ptr

这些智能指针有对数组的偏特化版本…

// auto test_arr = std::make_unique<int[]>(5);  // make_unique只有大小的支持，可以使用`[]`来初始化元素
std::unique_ptr<int[]> test_arr{new int[]{1,2,3,4,5}};
test_arr[0] = 999; // 如果使用std::unique_ptr<int> 就需要 test_arr.get()[0]这样的语法了

关于原始指针

虽然有了智能指针，但是稍微了解原始指针对于增长见识有帮助 (例如智能指针例如unique_ptr还是引入了overhead的，毕竟它利用了堆栈，不像原始指针可以寄存器上传递…

原始指针变量相当于“存入其它变量地址的值”的变量，它和地址稍有不同: 指针类型保留了对地址(内存)的解释方式（比如数组指针的自增增加的地址值不同），void*存储但没有解释地址，C中常用C-style Conversion来转换成其它类型以做到多态 (✿◠‿◠)?

int* a1 = new int(3);
int** a1_ptr = &a1; // 不能用一级指针去存指针的地址
std::cout << a1 << '\n'; // 0000015740779620
std::cout << *((int*)a1) << '\n'; // a1 相当于字符 0x0000015740779620
std::cout << **a1_ptr << '\n'; // 二级指针
std::cout << *((int*)(*a1_ptr)) << '\n'; //取一次地址相当于变成一级指针地址

标准库 Containers

initializer_list

在容器类型中增加接受std::initializer_list<T> 这样的参数（需要#include <initializer_list>），就可以支持使用{...}语法进行初始化，一般使用迭代器的写法去精细操作会比较方便

template<typename T>
void print(std::initializer_list<T> values)
{
  for (auto&& x: values)
  {
    std::cout << x << '\n';
  }
}

标准库算法两种版本

传统版本接受序列e.g.sort(begin(v),v.end())，范围版本接受一个单独的范围sort(v)，范围版本的必须在作用域内显示声明
